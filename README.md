# Healthcare Claims Payment Integrity Analytics

## Overview

This project analyzes synthetic healthcare insurance claims to identify payment patterns, potential overpayments, duplicate claims, unusually high-value claims, and providers that may require further investigation.

The project demonstrates the use of Python, SQL, and Power BI for healthcare payment integrity analytics.


## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI
- Git & GitHub
